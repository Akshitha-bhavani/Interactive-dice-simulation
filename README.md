# Interactive Dice Simulation

A simple interactive dice simulation application developed using Python and Tkinter.

## Overview

This project simulates rolling a six-sided dice through a graphical user interface.

When the user clicks the "Roll Dice" button, the application randomly selects a dice face and displays the corresponding result.

## Technologies Used

- Python
- Tkinter
- Random module

## Features

- Interactive graphical user interface
- Six-sided dice simulation
- Random dice selection
- Displays the dice face
- Displays the numerical result
- Button-based interaction

## How It Works

1. The application creates a graphical user interface using Tkinter.
2. The user clicks the **Roll Dice** button.
3. Python's random selection functionality chooses one of six dice faces.
4. The selected dice face is displayed on the screen.
5. The corresponding numerical result is shown below the dice.
